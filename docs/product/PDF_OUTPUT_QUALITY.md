# PDF 输出质量能力

## CAPABILITY

影谷长图阅读器用户可以把不同分辨率的图片片段排入同一份 A4 PDF。保存 PDF 时，程序按每张 A4 页的有效源分辨率在 72–300 DPI 之间选择输出分辨率，在减小文件和内存占用的同时保留该页可用的最高细节；打印始终生成 300 DPI 的临时 PDF，保证纸面输出稳定。

## CONSTRAINTS

- PDF 页面物理尺寸固定为 A4，预览、保存和打印使用同一套边距、栏数、栏间距和片段顺序。
- 保存 PDF 按页选择 DPI，不允许一个低分辨率片段降低其他 A4 页的分辨率。
- 同一 A4 页存在多个片段时，以保留该页最高可用细节为优先，页面 DPI 取各片段有效 DPI 的最大值，上限为 300。
- 保存 PDF 的最低页面分辨率为 72 DPI。低于该值不会产生更多细节，也不得破坏页面结构、页码或水印的物理比例。
- 打印固定为 300 DPI，不复用保存 PDF 的自适应质量策略。
- 任意非空源片段在输出中至少占 1×1 像素。无法安全量化时必须提高该页 DPI 或返回错误，不能静默丢失内容。
- 页码、水印等装饰元素按物理尺寸缩放，不随低 DPI 页面异常放大。
- 未注册用户的水印和页数限制规则保持不变。
- 导出完成状态显示实际 DPI；不同页面使用不同 DPI 时显示最小值到最大值。
- 导出失败不得报告成功，也不得把不完整文件当作有效结果交给用户。

## IMPLEMENTATION CONTRACT

### Actors and surfaces

- 保存 PDF：使用按页自适应质量策略，返回页面数、最低 DPI 和最高 DPI。
- 打印：使用固定 300 DPI 质量策略，再交给各平台打印对话框。
- 状态栏：成功后显示布局、每页片段数和实际 DPI 或 DPI 范围。

### States and transitions

1. 根据当前栏数和边距建立每张 A4 页的片段几何。
2. 保存时计算每页有效 DPI，并限制到 72–300；打印时直接使用 300。
3. 将浮点目标矩形安全量化为画布像素，保证非空矩形不会变成零宽或零高。
4. 渲染页面、水印和页码，写入 PDF。
5. 全部页面写入成功后返回统计数据并更新状态栏；任一步失败都返回明确错误。

### Interfaces and data

- PDF 导出入口接收显式质量策略，而不是从调用场景隐式推断。
- 页面 DPI 是页面级数据，PDF 中各页允许拥有不同的图像宽高，但 MediaBox 始终为 A4。
- DPI 聚合和 A4 像素尺寸计算放在可单元测试的核心模块中。

## NON-GOALS

- 本阶段不增加面向用户的“低/中/高”质量选择器。
- 本阶段不改变自动分页算法、栏布局规则或授权计费规则。
- 本阶段不承诺恢复低分辨率源图本身不存在的细节。

## OPEN QUESTIONS

- 72 DPI 最低值作为当前安全默认值。获得更多真实文件数据后，可在不改变接口的情况下调整。

## HANDOFF

该能力契约已可以直接实现。验收以混合分辨率、多栏、极端宽高比、页码、水印、打印固定 300 DPI 和真实 PDF 页面尺寸测试为准。
