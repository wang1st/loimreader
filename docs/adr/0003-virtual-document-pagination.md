# ADR-0003：虚拟长画布与提示驱动分页

## 状态

已接受并已实现核心

## 背景

直接把多张图片缩放后拼成一张位图，会使内存峰值与总像素量成正比。现有算法只在目标分割线附近寻找最白的一行，无法优先利用图片边界，也会在纯色背景或横线处误判。

## 决策

文档保存独立源图片和统一宽度下的虚拟坐标。页面保存引用源区域的切片，不保存拼接位图。断点候选来自图片边界、空白/低边缘行和人工位置，并在最短/最长页高内评分。

## 后果

### 正面

- 批量导入不会立即分配巨型位图。
- 分页、预览和导出共享同一坐标模型。
- 人工断点、图片边界和自动提示具有明确优先级且可测试。

### 负面

- 渲染一页可能涉及多个源图片和白色间隙。
- 解码层必须支持缓存或按页重复读取。

### 中性

- 分页规划只依赖图片尺寸和提示，图像解码可以异步完成。

## 备选方案

- **先拼大图再复用旧算法**：实现快，但高内存和整数溢出风险随批量数量放大。
- **固定 A4 高度硬切**：最简单，但会切断文字、表格和人物。
- **完整内容识别/机器学习切分**：效果潜力高，但模型体积、隐私和跨平台成本不符合当前阶段。
